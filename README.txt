# DayFlow オフライン対応版

## 含まれるもの
- `index.html` : アプリ本体（外部ライブラリ・CDN不使用）
- `manifest.webmanifest` : ホーム画面追加用の設定
- `sw.js` : アプリ本体をキャッシュするService Worker
- `icons/` : アプリアイコン

## iPhoneで使う手順
1. このフォルダ一式をHTTPS対応のWebホスティングにアップロードします（例：GitHub Pages）。
2. iPhoneのSafariで公開URLを開き、最初の読み込みを完了させます。
3. 共有ボタン →「ホーム画面に追加」→ 追加します。
4. 一度オンラインで開いてキャッシュが完了した後は、オフラインでも起動できます。

※ PWAとService Workerの仕様上、`file://` のHTMLを「ファイル」アプリから開くだけではオフラインPWAとしてインストールできません。HTTPSでの公開が必要です。
※ 予定は端末・ブラウザ内に保存されます。サイトデータの消去やブラウザ環境の変更で消える場合があります。別のURLに移行した場合、以前のデータは自動では引き継がれません。
